# Dish photos (demo)

One freely licensed photo per core dish, shown on the selected-dish card.

- Files: `<dish_id>.jpg` (matched by id, not by a contract field)
- Credits: `sources.json`
- Source script: `web/scripts/fetch_dish_images.py` (Wikimedia Commons; a couple of Flickr/Openverse fills)

Licenses are CC0, public domain, CC BY, or CC BY-SA. The card credits the photographer. Do not treat these as original TasteSpace photography.
