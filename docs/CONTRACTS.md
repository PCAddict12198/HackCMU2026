# Contracts (v1.0.0). OWNER: integrator

The machine-readable source of truth is **`contracts/src/tastespace_contracts/`** (pydantic). Everything
else is generated from it and drift-checked by `make check-contracts`:

| artifact | generated by | used by |
|---|---|---|
| `contracts/openapi.json` | `python -m tastespace.export_openapi` (FastAPI routes + models) | everyone |
| `contracts/generated/api.d.ts` | `openapi-typescript` | web (`src/contract.ts`) |
| `contracts/schemas/*.schema.json` | `python -m tastespace_contracts.export_schemas` | data (editor autocompletion) |
| `contracts/fixtures/api/*.json` | `tools/integrate/gen_api_fixtures.py` (rarely), validated in `contracts/tests` | web mock mode, contract tests |

## Frozen at h0-freeze
- **Taxonomy** (`taxonomy.py`): 17 `DimId`s in canonical order, `Course` (savory, dessert), 12 `FormatId`s,
  15 `ProcessId`s, 10 `CuisineId`s + region/macro hierarchy (cuisine distance 0 / 0.4 / 0.7 / 1.0),
  `Source`, `IngredientCategory`, `Panel`, `ToolName`. Ingredient/dish ids are free slugs `^[a-z][a-z0-9_]{1,40}$`.
- **Data** (`data_models.py`): Ingredient (profile `{dim: {v, src, note}}`, potency, unit_weight_g, density_g_per_ml),
  Process (scale/delta), Format (f), Dish (grams only), UnitsFile, AliasesFile, DishManifest, SanityPairs, RatingsFile.
- **API** (`api_models.py`): `GET /api/health`, `GET /api/space`, `GET /api/twins?dish=&k=`, `POST /api/shift`,
  `GET /api/explain?a=&b=`, `POST /api/recipe`, `POST /api/ask`. Similarity is always a **percentile**.
  Shift deltas and `target_z` are sigma units in [-2, 2].
- **Errors** (`errors.py`): `{"error": {"code", "message", "details"}}` with `validation_error` 422, `not_found` 404,
  `not_ready` 503, `grok_unavailable` 503, `grok_failed` 502, `internal` 500.
- **UI actions** (`ui_actions.py`), a discriminated union on `type`:
  ```json
  {"type":"select_dish","dish_id":"tonkotsu_ramen"}
  {"type":"show_twins","dish_id":"tonkotsu_ramen","highlight_dish_id":"french_onion_soup"}
  {"type":"set_shift","dish_id":"tonkotsu_ramen","deltas":{"rich":-0.8,"sour":1.2}}
  {"type":"explain_pair","a":"tonkotsu_ramen","b":"french_onion_soup"}
  {"type":"open_panel","panel":"shift"}
  {"type":"highlight_dishes","dish_ids":["pho_bo","tom_yum_goong"]}
  ```
  Actions carry ids only (never scores). Every referenced dish must exist and must appear in that turn's
  `tool_trace` (server-enforced). The UI ignores unknown action types.

## Change protocol
- Agents never edit contracts. They file a REQUEST in their handoff and keep working on the current contract.
- **Additive** (new optional field / endpoint / enum value): integrator hotfix on `main` any time ->
  `make contracts` -> bump `contracts/VERSION` and `CONTRACT_VERSION` (minor) -> `make fixtures` if shapes
  changed -> `make check` -> commit `[contract] v1.x` -> `git tag contract-v1.x` -> push -> announce.
  Owners merge `main` when convenient.
- **Breaking**: only at a checkpoint, major bump, agreed by all three roles.
